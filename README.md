# ATLAS UI Kit — практическая работа № 5

**Тема:** технический UI Kit для Help Desk  
**Репозиторий:** https://github.com/JustAuser677/ATLAS_UI_Kit_start

## Состав проекта

- `index.html` — демонстрационная страница компонентов UI Kit.
- `css/tokens.css` — примитивные, семантические и компонентные токены; светлая, тёмная и системная темы; компактная плотность.
- `css/components.css` — сетка, карточки, кнопки, поля, уведомления, состояния и адаптивные правила.
- `js/theme.js` — переключение темы и плотности с независимым сохранением в `localStorage`.
- `screenshots/` — снимки интерфейса для отчёта.
- `documents/` — исходные учебные материалы и образец оформления отчёта.
- `Отчёт_практическая_работа_5.docx` — отчёт по проекту.

## Запуск локально

1. Распакуйте архив.
2. Откройте папку `ATLAS_UI_Kit_FULL` в VS Code.
3. Откройте терминал в этой папке и выполните:

   ```bash
   python -m http.server 5500
   ```

4. Откройте в браузере <http://localhost:5500>.

Остановить сервер можно сочетанием `Ctrl + C` в терминале.

## Что реализовано

- Три режима темы: `auto`, `light`, `dark`. Ручной выбор имеет приоритет над настройкой ОС.
- Сохранение темы в `localStorage` под ключом `atlas-theme`.
- Два режима плотности: `normal` и `compact`. Сохранение отдельно под ключом `atlas-density`.
- Три вида кнопок: `primary`, `secondary`, `ghost`.
- Состояния кнопок: `hover`, `active`, `focus-visible`, `disabled`.
- Поля ввода: подпись, placeholder, hover, focus, disabled, invalid; ошибка связана с полем через `aria-describedby`.
- Четыре уведомления: `info`, `success`, `error`, `warning`.
- Адаптивные сетки и правила для узких экранов, включая ширину 320 px.
- Учет `prefers-reduced-motion`.

## Архитектура токенов

Примеры цепочек:

1. `--base-blue-700` → `--color-primary` → `--button-bg-primary` → фон `.button--primary`.
2. `--base-white` → `--color-on-primary` → `--button-text-primary` → текст `.button--primary`.
3. `--base-slate-950` → `--color-text` → `--control-text` → текст `.input` и `.select`.
4. `--base-white` → `--color-surface` → `--control-bg` → фон `.input` и `.select`.

Примитив содержит исходное значение, семантический токен задаёт назначение, компонентный токен связывает роль с конкретным компонентом. Цветовая тема переопределяет семантические роли, плотность — геометрические токены компонентов.

## Проверки перед сдачей

Проверить в браузере и зафиксировать результат в отчёте:

| Проверка | Что должно быть |
|---|---|
| Ширины 320, 375, 768, 1024, 1440 px | Нет горизонтального переполнения |
| `auto` при светлой/тёмной ОС | Соответствующая системная палитра |
| Ручные `light` и `dark` | Ручной выбор не зависит от темы ОС |
| Перезагрузка страницы | Тема и плотность восстанавливаются |
| `normal` → `compact` | Уменьшаются высоты и отступы компонентов |
| `Tab` / `Shift+Tab` | Видимый фокус на интерактивных элементах |
| Поле email с ошибкой | Видимая ошибка и связанное пояснение |
| Кнопки | Различимы default, hover, active, disabled |

Скриншоты в папке `screenshots` показывают состояния интерфейса. Они не заменяют самостоятельную проверку клавиатуры и контраста на целевых устройствах.

## Публикация через GitHub Pages

1. Откройте репозиторий GitHub.
2. Перейдите в **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `master` и каталог `/ (root)`, затем нажмите **Save**.
5. Дождитесь публикации. GitHub покажет адрес сайта в том же разделе Pages.

Если вы работаете с этим архивом как с отдельной копией, сначала загрузите его содержимое в корень репозитория. Не загружайте вложенную папку целиком, если `index.html` должен быть в корне публикации.

## Вопросы для защиты

**Почему плотность задаётся компонентными токенами?**  
Плотность изменяет высоты и отступы элементов управления, но не их смысловые цвета. Переопределение компонентных токенов позволяет использовать одни и те же CSS-правила без дублирования стилей.

**Почему тёмная тема не должна хранить прямые цвета внутри `.button`?**  
Прямые HEX-значения внутри компонента связывают кнопку с одной палитрой и усложняют поддержку тем. Кнопка использует семантические роли, значения которых централизованно меняются при переключении темы.
