ЧТО ПЕРЕДАТЬ ПРЕПОДАВАТЕЛЮ

1. GitHub-репозиторий:
   https://github.com/JustAuser677/ATLAS_UI_Kit_start

2. Рабочая страница UI Kit:
   После включения GitHub Pages адрес появится в Settings → Pages.
   Включить: Settings → Pages → Deploy from a branch → master → /(root) → Save.
   Если в репозитории уже есть исходники, загрузите обновлённые файлы проекта в корень репозитория.

3. Скриншоты:
   Сделайте свои скриншоты светлой и тёмной темы. Дополнительно рекомендуется
   тёмная + компактная и мобильная ширина 320 px.
   Подсказки находятся в папке screenshots.

4. Краткий отчёт:
   Файл «Отчёт_практическая_работа_5.docx».
   На титульном листе заполните ФИО и группу.

ЛОКАЛЬНЫЙ ЗАПУСК:
   python -m http.server 5500
   http://localhost:5500

Не отправляйте преподавателю эталонные изображения как собственные скриншоты.
